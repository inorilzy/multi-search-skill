# Rust/Tauri 修复与验证（2026-10-23）

## 威胁边界及逐项处置

- App 自定义命令此前未声明 ACL manifest；新增明确 command manifest 与 management 窗口 allow 列表（32 命令，含 reveal、scrape patch）。保持 `withGlobalTauri` 兼容现有无 bundler UI。ACL 不是 XSS 的替代防线：该窗口被攻陷仍可调用获准命令。Rust public fixture 并不自动成为 IPC；fixture feature 门控属于减少发布库辅助表面，并非声称已有远程任意执行。
- `credential_read` 每行前4后4掩码，长度<=8完全掩码；`credential_reveal` 是独立显式命令。`snapshot` 是原编辑文本 SHA-256；删除事务内验证摘要，不再向 WebView 索取明文快照。摘要不是密码学认证，当前进程仍有用户凭据权限。
- 明确路径只允许 PATH 实际发现的 multi-search.exe 或 LOCALAPPDATA 下受管的固定 executable，canonicalize 后对比；它不能防御同用户修改 PATH/替换已允许的程序。
- 搜索选项在前，`--` 后才放 query；合法 `--source=untrusted` / `--help` 查询按字面值保留。
- DesktopManager 的同一 mutation try_lock 覆盖 CLI install/update/uninstall 与 Skill install/update/remove；忙时 fail-fast。中毒变更锁故意 fail-closed 防止继续修改不确定安装。执行状态锁恢复 poison，process take 后释放锁再 finish/wait/join。IPC poll/cancel、SQLite、浏览器入口采用 spawn_blocking。
- Skill registry 临时文件 pid+counter；安装/备份目录 pid+时间戳；Skill install planning 和写入前均检查父链链接。安装完整性全 SHA-256 保留，没有以 size/mtime 弱化验证。未无证据引入全局性能缓存或合并大型模块；保留 skill/common/lifecycle 的职责分离。安装中重复的全局 Skill 路径解析改用共享 resolver。
- 子进程 4MiB截断具有 explicit Output.truncated；搜索返回明确失败。reader poison恢复。Windows Job Object 保持树终止；非Windows仅直接子进程终止的限制写在实现处。
- 环境秘密标记共用 process 常量；cookie 设置路径和 cookie 内容（含 BOM）参与脱敏，最短8字符以免毁坏正常文本。detect 一次调用共享同一秘密快照给两个probe，execution自带每次运行快照；没有永久缓存凭据导致陈旧泄露。
- Jina native editor save 改为与 metadata读取同一个 IMMEDIATE事务；fixture memory adapter只供测试，不代表生产事务。
- scrape_memory 显式SELECT列、版本1校验、hostname输入校验；未知版本拒绝读写。保留正式 CONFIG_DB/STATE_DB 环境覆盖兼容性，没有擅自禁用既有配置功能。
- 新增 scrape_settings_save(backends) 在IMMEDIATE事务内仅patch抓取链；settings/source页面省略该字段时原merge保留链。20轮竞争回归逐次断言 type、timeout、disabled_sources、future字段及链均保留。两个用户同时主动编辑同一字段仍是最后提交获胜，不声称全设置编辑器有CAS。
- Provider固定HTTPS申请链接启用 Brave/Exa/Tavily/Firecrawl/Jina/SerpAPI/GitHub/Parallel；Baidu未猜测控制台路径。
- PATH registry写入成功后通知失败不再返回保存失败；PathPlan.warning可告知重启宿主。通知独立线程，SMTO_ABORTIFHUNG有注释。
- ts-rs 为可选 `ts` feature；fixture辅助模块为 `test-fixtures` feature（或unit test）门控；普通集成测试需显式开feature。TypeScript生成测试ignored，普通漂移检查只读。自动比较window handler/API invoke命令和参数、ACL及manifest覆盖。
- 移位注释修正；去掉未用Win32_System_Memory；DPAPI无entropy的协议兼容性与同用户威胁限制写在代码中。

## 干净源码检查（不伪造 bundle）

在 `desktop/src-tauri` 执行 PowerShell：

```powershell
$env:TAURI_CONFIG = Get-Content tauri.check.conf.json -Raw
cargo check --all-targets --features test-fixtures,ts
cargo test --features install-test-boundary,ts
Remove-Item Env:TAURI_CONFIG
cargo test --no-default-features
cargo test --no-default-features --features test-fixtures
cargo test --no-default-features --features test-fixtures,ts --test ui_contract
```

检查overlay禁用打包及资源输入，只用于编译检查，不替代真实CLI bundle安装验收。没有受控bundle/anchor时正式默认cargo命令仍如实失败。3个原生/真实bundle测试保持ignored；类型生成另外1个ignored。显式生成：

```powershell
cargo test --no-default-features --features test-fixtures,ts --test ui_contract emit_types_d_ts -- --ignored
```

## 验证结果（2026-10-23，本机 Windows）

- `cargo test --no-default-features`：19 通过（17 lib + 2 install_release_boundary），0 ignored。
- `cargo test --no-default-features --features test-fixtures,ts`：172 通过，3 ignored（installed_cli 2 + emit_types_d_ts 1）。
- `TAURI_CONFIG` 检查overlay + `cargo check --all-targets --features test-fixtures,ts`：通过。
- `TAURI_CONFIG` 检查overlay + `cargo test --features install-test-boundary,ts`：211 通过，4 ignored（真实bundle 1、真实安装2、类型生成1）。
- 默认无overlay `cargo check` 仍因真实 `resources/cli-bundle` 缺失失败，这是真实资源验收约束，未被绕过。

## F-03 Baidu 申请入口（2026-10-23 复核）

具体产品为百度千帆「智能搜索生成高性能版」（`POST https://qianfan.baidubce.com/v2/ai_search/web_summary`，`X-Appbuilder-Authorization: Bearer <API Key>`）。百度官方文档《Python SDK调用对话Chat》在“如何获取 API Key”处给出固定入口 `https://console.bce.baidu.com/iam/#/iam/apikey/list`（同页亦见 [快速开始](https://cloud.baidu.com/doc/qianfan-docs/s/qm8qxemze) 的“控制台-安全认证-API Key”说明），故配置该官方 HTTPS 地址而不是猜测厂商营销页。测试断言映射存在且通过固定 HTTPS/无控制字符校验；未打开浏览器、未调用付费 API。UI 按钮仍由后端 `key_application_available` 控制，无需前端改动。

## 保留项 / 不成立项

- 不将 `withGlobalTauri` 本身等同漏洞；当前安全边界为CSP、无动态HTML注入（UI任务）及明确IPC allow列表。
- 不以 size/mtime替代完整性，不把性能建议当已复现安全漏洞；未进行可能破坏验证语义的大规模Skill模块合并。
- machine_paths与system初始快照重复计算只属微小启动优化，本轮保留，避免改变用户PATH/机器PATH语义。
- 原配置路径覆盖是受支持兼容入口而非页面直接输入，本轮不禁用。
- tests使用disposable profile/DB和专用接受测试注册表键，不运行真实bundle/用户安装ignored验收。
